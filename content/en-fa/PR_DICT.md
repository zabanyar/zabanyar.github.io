# en-fa pronunciation dictionary (PR_DICT)

One spelling per English word for the Persian-script `pr` guides of the English course (A1–C1). Every `pr` in every
level (words, `ex`, phrases, dialogue, reading, questions, grammar titles/examples/exercises, sentences, `cpr`) writes a
word exactly as listed here. Built in pass 5 (Nov 2026) from all levels: where a word was written in more than one way,
the spelling that follows the conventions and is most common was chosen and applied everywhere.

**Authors:** look a word up before writing its `pr`. A word that is not listed yet: follow the conventions below and the
spelling of related words (visit ویزیت → visitors ویزیتِرز, office آفیس → officer آفیسِر), then run
`python3 tools/en_fa_pr_dict.py build` to add it.

```
python3 tools/en_fa_pr_dict.py check     # pr tokens that differ from this file (run after writing content)
python3 tools/en_fa_pr_dict.py apply     # rewrite them to the spelling listed here
python3 tools/en_fa_pr_dict.py report    # words still written in more than one way
python3 tools/en_fa_pr_dict.py build     # add new words (existing entries are kept)
```

## Conventions (from content/CURRICULUM_NEW_LEVELS.md)

American pronunciation, written by sound. voiced th = ذ (the ذِ, that ذَت), voiceless th = ث (three ثری); /oʊ/ = ُو
(go گُو, home هُوم); /ɔr/ = ُر (for فُر, story سْتُری); /aʊ/ = او; /ɔɪ/ = ُی (boy بُی, point پُینت); /eɪ/ = ِی (day دِی);
/ɜr/ = ِر (work وِرک); schwa = ِ (problem پْرابْلِم); /æ/ = َ; /ʌ/ and /ɑ/ = ا; /u/ and /ʊ/ = و; /ɪ/ = ی; w = و;
kw = کْو (question کْوِسْچِن, quiet کْوایِت); sukun on initial clusters (پْلیز، سْتُری); "your" = یور; "me" = میْ;
silent letters not written; -ed = ت / د / ِد as pronounced. Persian names keep their normal Persian spelling (رضا، مریم).

## Words with more than one correct spelling (weak forms and homographs)

These are listed with " / " in the table. Choose by meaning or stress; never unify them.

| word | use |
|---|---|
| a | اِ; strong form / letter name اِی |
| can | کَن stressed (Yes, I can. / Can you …? / can't کَنت); کِن weak before a verb where a level uses it |
| close | کْلُوز verb (close the door); کْلُوس adjective (close to) |
| has | هَز; هَس only in *has to* |
| have | هَو; هَف only in *have to* |
| live | لیو verb; لایو adjective (live music) |
| lives | لیوْز verb (she lives); لایوْز noun (our lives) |
| read | رید present / infinitive; رِد past |
| the | ذِ before a consonant sound; ذی before a vowel sound |
| use | یوز verb; یوس noun |
| used | یوسْت in *used to* (habit); یوزْد = was used / used a … |

Other homographs (present, project, record, contract, estimate …) are listed with the spelling the course uses now
(mostly the noun); write the other reading by sound when it occurs and add a note here.
